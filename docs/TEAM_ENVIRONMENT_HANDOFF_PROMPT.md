# 给队友AI的接入核查提示词

如果队友已具备测试环境并准备实际验收，请使用新版[真实环境验收提示词](TEAM_LIVE_VALIDATION_PROMPT.md)。下方保留最初仅核查接入方式的提示词。

我们正在另一台电脑的AI-Bang2项目pd分支改进FinTech比赛五个场景，需要使用原团队的合成测试环境。请你检查你所在电脑上的项目和已有文档，帮我的队友整理一份可以转发给我的接入说明。

本轮只做本地只读核查。不要输出密码、API key、token、OAuth client secret、Cookie、完整一次性登录链接或私钥；不要导出钥匙串，不要发送消息、上传配置、修改平台资料或权限，也不要重启线上服务或调用付费模型。

请逐项确认，找不到就写“未找到”，不要根据旧聊天或文件名猜测：

1. 实际仓库路径、当前分支/commit、运行版本；服务在哪台电脑，哪些实例/端口正在供队友使用，哪些不可触碰。不要输出可能带密钥的完整进程参数或环境变量。
2. 四源配置文件和启动说明所在位置。仅给出路径、字段名称和脱敏结构，不贴原始配置内容；区别本机私有目录与可分享的无秘密模板。
3. Confluence、Jira、Slack、Google Drive分别使用什么认证方式，凭据存在哪里，是否有到期限制；哪些必须在新电脑重新登录/授权，哪些可通过团队批准的安全方式移交。不要创建新授权或扩scope。
4. 当前应用账号分别映射到哪个源身份；三个应用角色是否共用eng_b/team_knowledge。有没有可用的第二套独立原生测试身份？以别名描述，不输出不必要的私人账号信息。
5. 建议用于新增/修改/临时撤权验证的合成测试空间、项目、频道、文件夹和资料。给出可供团队定位的名称/ID及负责确认的人，说明会不会影响在线演示。已有明确授权和待授权操作分开列出，不因本提示词就认为权限变更已获批准。
6. 原有模型配置、费用账本、未知用量预留与测试额度限制。说明是否存在人工专用额度；不要把历史已用额度当成新预算。
7. 请最终输出：可直接转发的无秘密说明、需要人工安全交接的项目清单、尚缺信息/需要谁确认，以及新电脑接入前的最短检查步骤。尤其明确：哪些文件可以共享、哪些绝不能上传GitHub或贴进聊天。

我们收到说明后再制定测试计划。本提示词不要求你现在转移任何凭据、执行平台写入、撤权或部署。
